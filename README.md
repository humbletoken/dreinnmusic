# Dreinn Music

Telegram-бот с Mini App — музыкальный сервис, в котором треки и альбомы оцениваются
не одной цифрой, а по нескольким факторам. Итоговый **Dreinn Score — до 90 баллов**
с подробной разбивкой по критериям.

* Каталог и 30-секундные превью — **Deezer API** (без ключа)
* Плейлисты пользователя — **Spotify OAuth** (только метаданные, без скачивания и стриминга)
* Хранилище — **SQLite** (в Docker живёт на volume)
* Вся серверная логика — один файл `index.js`, клиент Mini App — папка `public/`

## 1. Система оценок

### Трек

Четыре базовых критерия, каждый 0–10 с шагом 0.5:

| Критерий | Что оценивается | Максимум в баллах |
|---|---|---|
| Тексты / образы | смысл, метафоры, подача | 18.75 |
| Структура / ритмика | аранжировка, флоу, динамика | 18.75 |
| Реализация стиля | убедительность жанра и звука | 18.75 |
| Индивидуальность / харизма | узнаваемость, характер | 18.75 |

```
база = (сумма четырёх критериев / 40) × 75        →  0 … 75
```

Пятый критерий — **Атмосфера / вайб** — не складывается, а превращается в коэффициент:

```
коэффициент = 0.80 + 0.04 × вайб                  →  ×0.80 … ×1.20
итог        = база × коэффициент                  →  0 … 90.0
```

### Альбом

Свои четыре критерия: **целостность, концепция, разнообразие, запоминаемость** —
и тот же множитель вайба. Дополнительно учитываются оценки отдельных треков альбома:

```
покрытие  = оценённых треков / всего треков
вес       = 0.4 × покрытие                        →  до 40 %
база      = собственная база × (1 − вес) + (средняя треков / 90 × 75) × вес
итог      = база × коэффициент вайба
```

### Шкала

| От | Уровень |
|---|---|
| 81 | Легенда |
| 72 | Великолепно |
| 63 | Отлично |
| 54 | Сильно |
| 45 | Хорошо |
| 36 | Средне |
| 27 | Спорно |
| 18 | Слабо |
| 0 | Мимо |

## 2. Возможности

**Mini App**

* поиск треков, альбомов и артистов;
* 30-секундные превью и мини-плеер;
* экран оценки с живым пересчётом балла и разбивкой;
* короткие отзывы и история оценок;
* любимые треки и альбомы;
* музыкальный профиль: архетип вкуса, распределение баллов, средние по критериям, топ артистов и жанров;
* умные подборки: «Ещё от X» (неоценённые треки тех, кого ты уже оценивал), «Похоже на X» (related-артисты Deezer), «В жанре Y» + блок «Артисты для тебя»; вес — от твоих оценок;
* Discover — колода находок: ~60 % под твой вкус + ~40 % новизны (редакция, чарт, жанровая волна);
* рейтинги треков, альбомов и слушателей;
* сравнение вкусов с другим пользователем (процент совпадения, согласия и разногласия);
* пользовательские коллекции;
* Spotify: плейлисты, оценка треков из них, импорт в коллекцию и выгрузка обратно;
* чарт и новые релизы обновляются в **00:00 по Москве** (часовой пояс настраивается);
* админ-панель для : привязка Spotify без правки , статистика, пользователи, рассылка, режим обслуживания.

**Бот**

`/start` `/app` `/search` `/rate` `/discover` `/top` `/profile` `/stats`
`/spotify` `/compare` `/scoring` `/help` + инлайн-режим (`@bot запрос`).
`/admin` — сводка и кнопка админ-панели (только для id из `ADMIN_IDS`).

Ответы бота используют **premium (custom) emoji** из набора «Telegram Ducks».
Если Telegram отклоняет custom emoji (бот без имени с Fragment), приложение
автоматически и навсегда для текущего процесса переключается на обычные эмодзи —
сообщения не теряются. Полностью выключить можно через `USE_CUSTOM_EMOJI=false`.

## 3. Быстрый старт

### Локально

```bash
npm install
cp .env.example .env      # заполнить BOT_TOKEN и PUBLIC_URL
npm start
```

По умолчанию в `.env` уже стоит `PUBLIC_URL=http://localhost:3000` и `DEV_MODE=true` —
Mini App открывается в обычном браузере на <http://localhost:3000> без Telegram.
**В продакшене обязательно `DEV_MODE=false`.**

### Docker

```bash
docker compose up -d --build
```

* `.env` **не попадает в образ** — он исключён в `.dockerignore` и подключается
  через `env_file` во время запуска;
* база лежит на именованном volume `dreinn-data` (`/data/dreinn.db`) и переживает
  пересборку образа; контейнер стартует под root только чтобы выдать права на
  этот каталог, после чего `docker-entrypoint.sh` уходит под пользователя `node`;
* порт `3000` проброшен наружу, есть healthcheck на `/healthz`.

Ручная сборка без compose:

```bash
docker build -t dreinn-music .
docker volume create dreinn-data
docker run -d --name dreinn-music -p 3000:3000 \
  --env-file .env -e DB_PATH=/data/dreinn.db \
  -v dreinn-data:/data dreinn-music
```

## 4. Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather | — |
| `BOT_USERNAME` | username бота без `@` (для ссылок «поделиться») | — |
| `PUBLIC_URL` | **домен с портом**, на котором доступен Mini App | `https://your-domain.com:3000` |
| `APP_DOMAIN`, `APP_SCHEME` | из них собирается `PUBLIC_URL`, если он пуст | `your-domain.com`, `https` |
| `PORT`, `HOST` | порт и интерфейс HTTP-сервера | `3000`, `0.0.0.0` |
| `BOT_MODE` | `polling` или `webhook` | `polling` |
| `WEBHOOK_PATH`, `WEBHOOK_SECRET` | путь и секрет вебхука | `/telegram/webhook` |
| `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET` | приложение Spotify | — |
| `SPOTIFY_REDIRECT_URI` | если пусто → `PUBLIC_URL + /spotify/callback` | — |
| `DB_PATH` | путь к файлу SQLite | `/data/dreinn.db` |
| `USE_CUSTOM_EMOJI` | premium-эмодзи в сообщениях бота | `true` |
| `DEV_MODE` | доступ к Mini App без Telegram initData | `false` |
| `ADMIN_IDS` | Telegram id администраторов через запятую (доступ к `/admin` и админ-панели) | — |
| `APP_TIMEZONE` | часовой пояс сервиса: обновление подборок в 00:00, «сегодня» в статистике | `Europe/Moscow` |
| `DEEZER_API` | база Deezer API | `https://api.deezer.com` |
| `CACHE_TTL` | TTL кэша внешних API, сек | `600` |
| `LOG_LEVEL` | `error` / `warn` / `info` / `debug` | `info` |

**Про домен с портом.** `PUBLIC_URL` — единственный источник правды: из него
собираются URL Mini App, ссылки в кнопках бота, адрес вебхука и redirect URI
для Spotify. Примеры: `https://dreinn.example.com`, `https://dreinn.example.com:3000`,
`http://localhost:3000`.

## 5. Настройка Telegram и Spotify

**@BotFather**

1. `/newbot` → получить `BOT_TOKEN`.
2. `/newapp` (или `/mybots` → Bot Settings → Menu Button) → указать URL Mini App —
   значение `PUBLIC_URL`. Telegram требует **HTTPS** (для локальной разработки
   подойдёт туннель вроде ngrok/cloudflared).
3. При старте приложение само вызывает `setMyCommands` и `setChatMenuButton`.

**Spotify Developer Dashboard**

1. Создать приложение → скопировать Client ID и Client Secret.
2. В Redirect URIs добавить ровно то, что окажется в `SPOTIFY_REDIRECT_URI`
   (по умолчанию `PUBLIC_URL + /spotify/callback`).
3. Scopes запрашиваются приложением автоматически: чтение профиля, плейлистов,
   топ-треков и создание плейлистов для выгрузки.

Треки Spotify сопоставляются с Deezer (по ISRC, затем по артисту и названию),
чтобы получить превью и оценку. Аудио Spotify не скачивается и не воспроизводится.

## 7. API

Все `/api/*` требуют заголовок `X-Init-Data` с `Telegram.WebApp.initData`
(подпись проверяется HMAC-SHA256 по схеме Telegram, срок жизни — 24 часа).
При `DEV_MODE=true` запросы без initData выполняются от тестового пользователя.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/bootstrap` | пользователь, конфиг критериев, шкала, статус Spotify |
| GET | `/api/home` | чарт, новинки, недавние оценки, сводка сообщества |
| GET | `/api/search?q=&type=` | поиск: `track` / `album` / `artist` |
| GET | `/api/track/:id` `/api/album/:id` `/api/artist/:id` | карточки объектов |
| GET | `/api/discover` `/api/recommendations` | находки и рекомендации |
| POST | `/api/rate` | сохранить оценку |
| POST | `/api/preview-score` | пересчитать балл без сохранения |
| DELETE | `/api/rate/:type/:id` | удалить оценку |
| GET | `/api/ratings` | история с фильтрами и сортировкой |
| GET/POST/DELETE | `/api/favorites` | любимое |
| GET | `/api/profile?userId=` | профиль и статистика |
| GET | `/api/leaderboard` | рейтинги треков, альбомов, слушателей |
| GET | `/api/users?q=` · `/api/compare/:userId` | поиск людей и сравнение вкусов |
| CRUD | `/api/collections` | коллекции и их содержимое |
| — | `/api/spotify/*` | статус, авторизация, плейлисты, импорт, экспорт |
| GET | `/healthz` |healthcheck для Docker |

## 8. Дизайн

Мультяшный «стикерный» стиль в тёмно-белой гамме: толстые обводки, жёсткие
смещённые тени, плавающая нижняя навигация, крупные обложки, пружинные
микроанимации, skeleton-загрузка и мини-плеер. Тема подхватывается из Telegram
(`colorScheme` + `themeChanged`), есть светлый и тёмный вариант.

* Шрифты: **Nunito** (интерфейс и заголовки, 900 для акцентов) и **Caveat**
  (рукописные подписи), оба с кириллицей.
* Иконки: **[Lucide](https://lucide.dev)** (ISC) и брендовые из
  **[Simple Icons](https://simpleicons.org)** (CC0) — они собраны в
  `public/js/icons.js`; эмодзи в интерфейсе не используются.

## 9. Админ-панель

Доступна пользователям из `ADMIN_IDS`: Профиль → Админ-панель, или команда
`/admin` в боте. Всё хранится в таблице `settings` и перекрывает `.env`.

| Вкладка | Что умеет |
|---|---|
| Обзор | пользователи/оценки за сегодня и неделю, состояние бота, Spotify, кэша, БД; последние оценки; кнопки «обновить подборки» и «очистить кэш» |
| Spotify | ввод Client ID / Secret / Redirect URI; ключи проверяются запросом к Spotify **до** сохранения; кнопка копирования redirect URI; возврат к ключам из `.env` |
| Настройки | premium-эмодзи бота, часовой пояс (чипсы + произвольный IANA), режим обслуживания с текстом |
| Люди | поиск, бан/разбан с причиной, удаление всех оценок пользователя, переход в профиль и сравнение |
| Рассылка | сообщение всем пользователям бота (HTML), тест себе, прогресс в реальном времени |
| Бот | getMe, состояние вебхука, переустановка команд и кнопки меню |

Секрет Spotify наружу не отдаётся (только маска), `DEV_MODE`, `BOT_TOKEN` и
`ADMIN_IDS` из панели менять нельзя намеренно.

## 10. Подборки и ежедневное обновление

Движок (`recommendationEngine` в `index.js`) строит семена вкуса из оценок:
артисты с весом `avg − 30 + min(count, 5) × 4` (оценки ниже 40 семенами не
становятся) и жанры. Кандидаты берутся из трёх источников — топ-треки тех же
артистов, related-артисты Deezer и артисты любимых жанров — взвешиваются,
дедуплицируются, уже оценённое исключается, один артист не идёт больше двух
позиций подряд. Кэш на 30 минут и сбрасывается при новой оценке.

Чарт, выбор редакции и новые релизы кэшируются с ключом, привязанным к дате в
`APP_TIMEZONE`, а TTL истекает ровно в 00:00 этого пояса; планировщик в полночь
прогревает кэш заново. Поэтому «новое» появляется в 00:00 по Москве, а не по UTC.

## 11. Если что-то не запускается

### `SqliteError: unable to open database file` (`SQLITE_CANTOPEN`)

Каталог с базой принадлежит `root`, а приложение работает под пользователем
`node` (uid 1000). Обычно так бывает с томом, созданным более ранней версией
образа, или с bind-mount с хоста. Начиная с этой версии `docker-entrypoint.sh`
чинит права автоматически при старте, поэтому достаточно пересобрать образ:

```bash
docker compose up -d --build
```

Если вы запускаете контейнер своим способом (или принудительно через
`--user`), права можно выдать вручную:

```bash
# существующему тому
docker run --rm -v dreinn-data:/data alpine chown -R 1000:1000 /data

# либо пересоздать пустой том (данные будут потеряны)
docker compose down && docker volume rm dreinn-data && docker compose up -d --build
```

Приложение печатает при такой ошибке путь к файлу, владельца каталога, uid
процесса и эти же команды — гадать не придётся.

### Mini App пишет «Что-то пошло не так» при запуске из Telegram

Сервер отклонил подпись `initData`. Точная причина видна в ответе API и в логах
(`docker compose logs -f dreinn-music`), сообщение уже переведено на человеческий:

| reason | что делать |
|---|---|
| `hash_mismatch` | `BOT_TOKEN` на сервере не от того бота, через которого открыт Mini App |
| `bot_token_not_set` | `BOT_TOKEN` не передан в контейнер (проверьте `.env` и `env_file`) |
| `expired` | `initData` старше 24 часов — просто переоткройте приложение |
| `no_init_data` | приложение открыто не из Telegram (в браузере поможет `DEV_MODE=true`) |

После обновления кода обязательно пересоберите образ: клиентские файлы отдаются
с `Cache-Control: no-cache` и перепроверяются по ETag, но старый образ продолжит
отдавать старый `index.js`.

### Бот не отвечает

* проверьте `BOT_TOKEN` и логи: `docker compose logs -f dreinn-music`;
* при `BOT_MODE=webhook` нужен публичный HTTPS-адрес в `PUBLIC_URL`
  и совпадающий `WEBHOOK_SECRET`;
* Mini App не открывается из кнопки — Telegram требует HTTPS в `PUBLIC_URL`.

### Custom emoji приходят обычными

Telegram разрешает ботам premium-эмодзи только при купленном на Fragment
username. Приложение само определяет отказ и переключается на обычные эмодзи;
принудительно — `USE_CUSTOM_EMOJI=false`.
